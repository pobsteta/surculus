# Correspondance avec la nomenclature provisoire de sommieR

Propriétaire : Pascal. Consulté le 2026-10-15. **La liste complète des 15 codes `SOMMIER_CODES_TRAVAUX` n'est pas disponible dans ce dépôt** (le code de sommieR n'y est pas). Ne sont connus que : PS, PL, RG, PG, PI, DG, CL, NT (brief.md) et RN, DS (briefs/vers-sommier/2026-10-15-travaux-3-programme.md). Cinq codes manquent. Les libellés ne sont donnés que là où un brief les associe à un type d'action ; je n'invente pas les autres.

| Code sommieR | Sens documenté | Équivalent trouvé dans les sources | Remarque |
|---|---|---|---|
| PL | action `plantation` | Plantation | Correspondance de libellé |
| RN | action `regeneration` | Dégagement/compléments de régénération naturelle (partiel) | Ambigu : « régénération » peut être le travail de régénération ou son entretien |
| PI | action `protection` | Protection contre les animaux | Lettres PI laissent croire à « protection individuelle »; non documenté |
| CL | `cloisonnement` | aucun dans les sources plantation | Exclu du barème placeau de l'aide (travaux accessoires) |
| NT | `depressage` | Nettoiement-dépressage | Ambigu : NT = nettoiement ou dépressage ? Les sources les couplent mais distinguent du dégagement |
| DG | `entretien` | Dégagement de plantation | Ambigu : l'action est nommée « entretien », le code évoque « dégagement » |
| DS | `desserte` | aucun | Hors plantation |
| PS | non documenté | possible préparation de sol (hypothèse à vérifier) | Signification non connue |
| RG | non documenté | possible regarni (hypothèse) | Idem |
| PG | non documenté | ? | Idem |

Codes sans équivalent dans les sources : CL, DS (et peut-être PG). Libellés des sources sans code sommieR identifiable : contrôle de la végétation ligneuse, élimination de la végétation herbacée (peut-être inclus dans DG), enrichissement, notation/constat de reprise (le contrôle est un geste de Surculus, pas un code travaux).

Constat : aucun des 15 codes ne vient d'une convention externe, et aucune convention externe codée n'a été trouvée. Le conflit à trancher n'est donc pas « code sommieR contre code ONF » mais « garder un code interne documenté, ou obtenir le RNTSF/codes ONF ».
